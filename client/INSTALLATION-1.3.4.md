# NEI Level Maintainer 1.3.4 installation

**Default polling frequency is deliberately very low to minimize server load.**
The ordinary cycle/header is 60 seconds; stocked-item checks are 5-60 minutes
apart. Replenishment can be slow. See the [complete setup guide](../docs/INSTALLATION.md)
for the exact profile and how to adopt it on an existing installation.

The [release](https://github.com/dronf/Level-Maintainer/releases/tag/nei-level-maintainer-1.3.4)
includes the built JAR, matching OC scripts, source, offline guides and checksums.
Existing saved settings and maintained entries are preserved. An existing 1.3.3
client JAR is compatible with the Lua update.
