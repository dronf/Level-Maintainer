# NEI Level Maintainer 1.4.0 installation

Replace the previous client addon JAR with nei-level-maintainer-1.4.0.jar while
Minecraft is closed. Keep exactly one version. Existing Lua 1.3.4 needs no update.

In Minecraft Options -> Controls -> NEI Level Maintainer, assign Open manager
shortcut to an unused keyboard key (default unbound, modifier NONE). Open the
manager with it, click Shortcuts, then set the context key to an unused key and
modifier NONE, or unbind context. Done saves immediately. This frees Ctrl and M
when they are assigned to Matter Manipulator and a universal terminal.
